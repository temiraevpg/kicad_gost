# Работа в KiCAD по ГОСТ

Данный репозиторий - это попытка сделать оформление схемы по ГОСТ. 

## Порядок использования

- Скачайте данный репозиторий себе на компьютер
- Пропишите таблицу библиотек компонентов в KiCAD
- Примените настройки
- Установите директорию `{KICAD_GOST_DIR}` в пути приложения
- Пользуйтесь!

## Особенности оформления схем

При оформлении схем следует использовать сетку в 2.5мм. Однако становится невозможно установить соединени проводника к шине. Для решения этой проблемы следует скопировать строчку `(bus_entry (size 2.5 2.5))` и вставить на схеме через `CTRL` + `V`.
